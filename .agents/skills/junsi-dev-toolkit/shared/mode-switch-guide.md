# Plan 模式与 Build 模式切换指南

## 两种模式的区别

| | Plan 模式 | Build 模式 |
|:---|:---|:---|
| 能修改文件？ | ❌ 不能 | ✅ 能 |
| 能运行命令？ | ❌ 不能 | ✅ 能 |
| 职责 | 分析、规划、输出文本 | 执行、修改、验证 |

## 在 Plan 模式下的工作流

1. 分析问题/需求
2. 输出分析结果
3. 输出详细执行计划
4. 在计划末尾输出切换指引

## 在 Build 模式下的工作流

1. 确认计划
2. 按计划执行修改
3. 编译验证
4. 若失败则诊断修复
5. 测试验证
6. 完成

## Plan 模式输出末尾的统一切换指引模板

```markdown
---
## 📌 下一步操作

以上是完整的执行计划。请执行以下操作：

1. 确认计划内容无误
2. **切换到 Build 模式**（在界面中关闭 Plan 模式）
3. 回复 **"执行"** 或 **"开始"**
4. 我将按计划逐步实施，并在每一步进行编译验证
---
```
