# 冲突矩阵模板

移植前必须输出此表。若存在冲突项（目标已有类似功能），必须暂停询问用户。

## 格式

| 源功能/文件 | 源实现方式 | 目标已有实现 | 冲突类型 | 处理建议 |
|---|---|---|---|---|
| `src/auth/login.go` | JWT + Redis session | `AuthService.java` 使用 Spring Security | 覆盖 | **询问用户：覆盖目标实现 or 适配共存？** |
| `src/utils/date.go` | 自定义日期格式化 | 无 | 新建 | 直接移植 |
| `src/models/user.go` | GORM 模型 | `UserEntity.java` (JPA) 字段一致 | 重复 | 跳过，目标已有等价实现 |

## 冲突类型

| 类型 | 含义 | 处理方式 |
|---|---|---|
| 覆盖 | 目标已有同名/同功能实现，逻辑可能不同 | **必须询问用户** |
| 新建 | 目标无此功能 | 直接移植 |
| 重复 | 目标已有等价实现 | 跳过 |
| 共存 | 功能相似但业务场景不同 | **必须询问用户**如何命名和组织 |
